The portfolio combines **editorial design, motion, interaction, and technology** to create a personal space that feels as intentional as the work it presents.

## ◇ ARCHITECTURE

```text
Portfolio/
│
├── public/
│   └── assets/
│       ├── images/
│       ├── certificates/
│       └── other media
│
├── src/
│   ├── App.jsx
│   ├── data.js
│   └── styles.css
│
├── index.html
├── package.json
├── .gitignore
└── README.md
```

### Core files

**`src/App.jsx`**
Interactive sections, components, and portfolio structure.

**`src/data.js`**
Centralized portfolio content, projects, achievements, skills, and personal information.

**`src/styles.css`**
Responsive layout, typography, animation, visual system, and interaction styling.

**`public/assets/`**
Local images, screenshots, certificates, and other portfolio media.

## ◇ RUN LOCALLY

Clone the repository:

```bash
git clone https://github.com/nisha-razzaq/Portfolio.git
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite.

---

## ✦ PRODUCTION

Build:

```bash
npm run build
```

Preview:

```bash
npm run preview
```

## ◈ EDITING CONTENT

Most personal information lives inside:

```text
src/data.js
```

You can update:

```text
Projects
Skills
Experience
Achievements
Certifications
Personal information
Descriptions
```

Local media belongs inside:

```text
public/assets/
```

and can be referenced as:

```text
/assets/filename.ext
```

---

## ◇ MEDIA

Large video files are intentionally excluded from Git tracking.

The repository ignores:

```text
*.mp4
```

This keeps the Git repository lightweight while allowing videos to remain available locally during development.
